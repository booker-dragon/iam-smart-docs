`code` in every response and callback is `D00000` on success. The table lists every code in the v2.5.2 specification; the *What to check* column is this site's guidance, not part of the spec.

<Aside type="tip">

</Aside>

Status codes for bulk signing (`SS001`–`SS006`) are returned by [Enquire Bulk Digital Signing Status](/api/operations/enquire-bulk-signing-status/); acknowledgement values (`SR001`–`SR003`) are sent by you in the *acknowledge* APIs.
