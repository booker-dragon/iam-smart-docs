The iAM Smart gateway only accepts signed, encrypted requests. These tools produce exactly what it expects and read what it sends back. To send a request for a specific API, use the **Try it** console at the top of its page in the [API reference](/api/) — it shares your CEK, tokens and other session values across pages. For guided flows, try the [anonymous step-up](/playground/anonymous-step-up/) and [anonymous form filling](/playground/anonymous-form-filling/) playgrounds.

<Aside type="caution" title="Your secrets stay here">
  All tools run in this page with the browser's Web Crypto API. Nothing you type is uploaded. Still, use **testing-environment** credentials and keys only. Non-secret fields (client ID, endpoint, environment) are remembered in this browser for convenience.
</Aside>
